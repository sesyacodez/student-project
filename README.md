# EduManage - Система управління навчальним центром 

Цей проєкт складається з Django REST API (бекенд) та Vanilla JS (фронтенд). Інфраструктура повністю контейнеризована за допомогою Docker та використовує PostgreSQL.

## Швидкий запуск (Docker)

1. **Налаштування середовища:**
   Скопіюйте файл-шаблон `.env.example` та перейменуйте його на `.env` (або просто створіть файл `.env` і скопіюйте туди вміст).
   
2. **Запуск контейнерів:**
   Переконайтеся, що Docker запущений, і виконайте команду в корені проєкту:
   ```bash
   docker-compose up -d --build
